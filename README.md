# Crop Prediction Model (REST API):
A machine learning-powered web application designed to help farmers and agricultural enthusiasts predict the most suitable crop to grow based on soil and environmental parameters.

# Live Demo:
Check out the live application here:
[https://crop-prediction-model-rest-api.onrender.com/]

# Features:

Data-Driven Predictions: Predicts the best crop using Nitrogen, Phosphorus, Potassium, Temperature, Humidity, and pH levels.
User-Friendly Interface: A clean, responsive UI featuring a customized agricultural background and styled input forms.
REST API Integration: Built with a Flask backend to handle prediction requests efficiently.
Ready for Deployment: Includes all necessary configurations like Dockerfile, Procfile, and requirements.txt for cloud hosting.

#Tech Stack:

Frontend: HTML5, CSS3
Backend: Python (Flask Framework)
Machine Learning: Scikit-learn, Pandas, NumPy
Deployment: Render, GitHub
📂 Project Structure
static/: Contains the CSS styling (style.css) and background images (app.jpeg).
templates/: Contains the frontend HTML (index.html).
app.py: The main Flask server file.
Crop_recommendation.csv: The dataset used for training and reference.
